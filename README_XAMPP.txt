ABSHIRO MASJID PRAYER TIME V2
=============================
V2 keeps the same MySQL database name: abshiro_masjid

XAMPP:
1. Start Apache + MySQL.
2. Keep this folder inside C:\xampp\htdocs\
3. Do NOT import a new database if abshiro_masjid already exists.
4. Open:
   http://localhost/ABSHIRO_MASJID_PRAYER_TIME_V2/

If you already have the working V1 database, V2 uses it directly.
If you rename the folder, the URL changes accordingly.

Adhan:
Place an authorized/licensed complete recording at:
assets/adhan.mp3
Then press Enable Adhan once in the browser.
If the MP3 is unavailable, the browser's Arabic speech fallback may be used.

Before GitHub/Vercel:
Test locally first. The current config is for local XAMPP MySQL.
For Vercel, an online MySQL database and environment variables will be configured separately.
